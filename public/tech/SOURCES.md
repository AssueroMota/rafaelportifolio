# Icones de tecnologias

Os SVGs sao locais para evitar dependencia de um CDN durante a exibicao.

- JavaScript, TypeScript, React, Next.js, HTML5, CSS3, Sass, Vite, Node.js,
  Express, GraphQL, Python, Mongoose, Redis, MySQL, Docker, Git, AWS e Linux:
  https://github.com/devicons/devicon/tree/master/icons.
- Devicon: licenca MIT, incluida em `LICENSE-devicon.txt`. As marcas pertencem
  aos respectivos proprietarios.
- MongoDB: https://cdn.simpleicons.org/mongodb/47A248, do projeto
  https://github.com/simple-icons/simple-icons.

O icone Sass representa a skill Sass / SCSS.
